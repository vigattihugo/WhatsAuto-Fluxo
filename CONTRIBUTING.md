# Contributing to WhatsAuto

Obrigado por se interessar em contribuir! 🎉

## Código de Conduta

Seja respeitoso com todos os colaboradores.

## Como Contribuir

### Reportando Bugs

- Abra uma [Issue](https://github.com/seu-usuario/whatsauto/issues)
- Descreva o comportamento esperado vs atual
- Inclua screenshots/logs se aplicável

### Sugerindo Features

- Abra uma [Discussion](https://github.com/seu-usuario/whatsauto/discussions)
- Explique o caso de uso
- Exemplos de código são bem-vindos

### Pull Requests

1. Fork o repositório
2. Crie uma branch: `git checkout -b feature/sua-feature`
3. Commit com mensagens claras: `git commit -m 'feat: descrição'`
4. Push: `git push origin feature/sua-feature`
5. Abra um PR com descrição do que foi mudado

### Padrões de Código

- TypeScript com tipos explícitos
- Componentes React funcionais com hooks
- Tailwind CSS para estilo (evite CSS customizado)
- Commit messages em inglês (descrição em português OK)

### Setup Local

```bash
git clone https://github.com/seu-usuario/whatsauto.git
cd whatsauto
npm install
npm run dev
```

## Estrutura do Projeto

```
src/
├── components/        # Componentes React reutilizáveis
├── data/             # Dados estáticos (módulos Python, stats)
├── utils/            # Funções utilitárias
├── App.tsx           # Componente raiz
└── main.tsx          # Entry point
```
